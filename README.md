# Tarkle Homebrew tap

```
brew tap tarkleHQ/tap
brew install tarkle
```

Installs the Tarkle command line (`tarkle`), a tool for the Tarkle API: files, folders, uploads, brand pages and access requests.

Status: the formula is not live yet. It goes into `Formula/` after `@tarkle/cli` is published to npm (see `templates/tarkle.rb.in`).
