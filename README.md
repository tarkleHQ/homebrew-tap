# Tarkle Homebrew tap

```
brew tap tarkleHQ/tap
brew install tarkle
```

Installs the Tarkle command line (`tarkle`), a tool for the Tarkle API: files, folders, uploads, brand pages and access requests.

Updating: publish a new `@tarkle/cli` version to npm, then set `url` and `sha256` in `Formula/tarkle.rb` (`templates/tarkle.rb.in` is the blank form).
